# @mptool/shared

Shared utilities for the mptool packages and WeChat mini-programs.

Most users do not need to install this package directly: `@mptool/all` and `@mptool/skyline`
re-export the commonly used members.

- `Emitter` / `userEmitter`
- `logger`, `query`, `env`
- `MpError`
- `type`, `isFunction`, `wrapFunction`
- `lock`, `once`
- `Queue`, `funcQueue`, `createQueue`
- `encodeBase64`, `decodeBase64`

Docs: <https://miniapp-tool.github.io/shared/>
